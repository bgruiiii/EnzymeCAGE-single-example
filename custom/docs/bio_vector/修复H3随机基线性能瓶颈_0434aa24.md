# 修复 H3 Random Baseline 性能瓶颈并完成 Task 0

## 问题诊断

`analytical_random()` 函数（L403-422）对每个 group **逐一** 计算 O(N-gs) 的 MRR 循环：
- UniProt: 107731 groups × ~145607 iterations ≈ 15.7B 次循环 → **卡死**
- EC-2/EC-3/EC-4: 66/187/2536 groups → 可接受

**根因**：大多数 UniProt group size=1（singleton），每个 singleton 的 MRR 循环需要 ~145607 次迭代。

## 优化方案：Group-Size 去重

核心思想：`analytical_random` 的结果只取决于 group size `gs` 和 N。相同 size 的 group 结果完全一样。

```
原始：for gs in group_sizes:  compute(gs)  → O(num_groups × N)
优化：for gs in unique_sizes:  compute(gs)  → O(num_unique_sizes × N)
      result = weighted_average by count
```

UniProt 107731 groups 可能只有 ~100-500 个 unique size → **加速 200-1000x**

## Task 1: 优化 `analytical_random` 函数

**文件**: `/public/home/acfbwjsi7s/bio_vector_full_run_2026-06-04/code/demo/diagnose_round1_postmortem.py`

**修改 L403-422**，替换 `analytical_random` 为按 unique size 去重版本：

```python
def analytical_random(group_sizes, N):
    from collections import Counter
    size_counts = Counter(group_sizes)  # {gs: count}
    total_groups = len(group_sizes)
    
    weighted_t1, weighted_t5, weighted_t10, weighted_mrr = 0.0, 0.0, 0.0, 0.0
    
    for gs, cnt in size_counts.items():
        # top-k (unchanged logic)
        def topk(k):
            if gs >= N: return 1.0
            k = min(k, N)
            lp = sum(np.log(max(N-gs-i, 1e-300)) - np.log(max(N-i, 1e-300))
                     for i in range(min(k, N-gs)))
            return 1.0 - np.exp(lp)
        t1, t5, t10 = topk(1), topk(5), topk(10)
        
        # MRR (unchanged loop logic)
        mv = 0.0; ps = 1.0
        for r in range(1, N-gs+2):
            if r > 1: ps *= max(N-gs-r+2, 1) / max(N-r+2, 1)
            pp = ps
            pn = ps * max(N-gs-r+1, 1) / max(N-r+1, 1) if r < N-gs+1 else 0.0
            mv += (pp - pn) / r
            if pn < 1e-15: break
        
        weighted_t1 += t1 * cnt
        weighted_t5 += t5 * cnt
        weighted_t10 += t10 * cnt
        weighted_mrr += mv * cnt
    
    return {
        "top1": weighted_t1 / total_groups,
        "top5": weighted_t5 / total_groups,
        "top10": weighted_t10 / total_groups,
        "mrr": weighted_mrr / total_groups,
    }
```

**关键变更**：
- 用 `Counter(group_sizes)` 统计每个 unique size 的出现次数
- 只对每个 unique size 计算一次
- 结果按 count 加权求和，最后除以 total_groups
