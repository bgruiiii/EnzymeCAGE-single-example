## 3. Working Hypothesis

R1 aligns reaction and enzyme well at EC-family and EC-functional levels:

- EC-2-grouped `R→E MRR = 0.9340`
- EC-3-grouped `R→E MRR = 0.933629`
- EC-4-grouped `R→E MRR = 0.918680`

The remaining problem is fine-grained row-level / UniProt-level discrimination:

- row-level `R→E MRR = 0.0580`
- UniProt-grouped `R→E MRR = 0.0581`

The diagnosis supports two interacting causes:

1. H1: hard-negative mining is too coarse.
   - same-EC-1-digit per-anchor mean is `643.96`, above the `500` threshold.
   - With `hard_neg_weight = 2.0`, broad same-EC-1 negatives are upweighted.
   - This can push biologically related enzymes apart at a granularity broader
     than the row-level / UniProt-level retrieval target.

2. H3: Stage 1 is undertrained at full-data scale.
   - Stage 1 directly trains the pairwise `R↔E` and `E↔M` objectives.
   - Full-data complexity increased far more than the number of Stage 1
     optimization steps.
   - More Stage 1 optimization is needed after removing coarse hard-negative
     pressure.

R2 should therefore remove extra same-EC hard-negative pressure and increase
Stage 1 optimization, while preserving the strong EC-2/EC-3/EC-4 structure.

## 4. Approved Training Variables For R2

Use the full ESM-C enzyme feature mode.

Change only these training hyperparameters:

```python
hard_neg_weight = 1.0      # R1 was 2.0
epochs_stage1 = 25         # R1 was 12
```

Interpretation:

- `hard_neg_weight = 1.0` disables extra same-EC hard-negative upweighting.
- Same-EC examples remain ordinary InfoNCE negatives.
- `epochs_stage1 = 25` gives the direct `R↔E` / `E↔M` training stage more
  full-data optimization time.

Do not change EC encoding in R2 training.

Reason:

```text
When hard_neg_weight = 1.0, the same-EC weighting term degenerates to 1.0, so
the same_ec matrix does not affect the InfoNCE logits. Changing EC encoding in
the same R2 run would be a dead-code/confounding variable.
```

EC encoding changes may be considered later as an R3 ablation, not in R2.

## 7. Quantitative Pass / Warning Thresholds

| Metric | R1 measured | R2 pass threshold | Warning / failure threshold |
|---|---:|---:|---:|
| row-level `R→E MRR` | 0.0580 | > 0.12 | < 0.06 means failure |
| UniProt-grouped `R→E MRR` | 0.0581 | > 0.15 | < 0.08 means failure |
| EC-4-grouped `R→E MRR` | 0.918680 | >= 0.868680 | drop > 0.05 means warning |
| EC-2-grouped `R→E MRR` | 0.9340 | >= 0.85 | < 0.70 means severe degradation |
| E→M MRR | 0.609 | >= 0.55 | < 0.40 means failure |

R2 success rule:

```text
R2 is successful if row-level or UniProt-grouped R→E reaches its pass threshold
and EC-2/EC-4 grouped metrics do not cross warning thresholds.
```

R2 warning pattern:

```text
If row-level / UniProt-grouped metrics improve but EC-2 or EC-4 grouped metrics
drop below threshold, R2 improved fine discrimination at the cost of functional
structure and should not be treated as clean success.
```
